# AVENOIR — Grocery-style E-commerce UI

A standalone responsive e-commerce storefront inspired by the supplied reference image.
Open `index.html` directly in a browser.

Included:
- Reference-inspired rounded orange/cream visual system
- Responsive hero/navbar
- Product carousel
- Product search
- Working add-to-cart and cart drawer
- LocalStorage cart persistence
- Trust/shipping section
- Mobile responsive layout

The product photos are loaded from Unsplash URLs, so an internet connection is needed for the images.
